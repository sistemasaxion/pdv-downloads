## Instalação

1. [Baixe o instalador](https://github.com/sistemasaxion/pdv-downloads/releases/latest/download/Axion-PDV-Instalador.exe) e abra o arquivo.
2. Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece com programas novos que ainda não são conhecidos pelo Windows. O instalador é o mesmo publicado nesta página.
3. A instalação termina sozinha e cria o atalho na área de trabalho. Na primeira abertura, informe o nome e o tipo do seu negócio e crie o seu usuário de administrador.
4. Use por 7 dias grátis. Para continuar, digite o código de ativação que você recebeu na compra (Configurações > Licença).

O suporte fica dentro do sistema: aperte **Ctrl+F1** em qualquer tela.
